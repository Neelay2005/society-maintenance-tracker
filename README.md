# Society Maintenance Tracker

A web platform for apartment societies to manage maintenance complaints end-to-end. 
Residents can raise complaints with photos and track their status in real time, while 
admins manage the complaint lifecycle through a structured workflow — setting priorities, 
updating statuses, and flagging overdue issues. The platform also includes a notice board 
for society-wide announcements and sends email updates to residents on status changes and 
important notices.

## Problem
Apartment societies typically handle maintenance complaints through informal channels 
(WhatsApp, phone calls, registers), leaving admins with no clear view of what's pending, 
overdue, or recurring — and residents with no visibility into progress.

## Key Features
- **Resident**: Register/login, raise complaints (category, description, photo), 
  track full status history of each complaint
- **Admin**: View and filter all complaints (by category, status, date), set priority 
  (Low/Medium/High), update status (Open → In Progress → Resolved) with timestamped notes
- **Overdue Detection**: Complaints open beyond a configurable threshold are auto-flagged 
  and surfaced at the top of the admin view
- **Notice Board**: Admin-posted notices, with important ones pinned to the top
- **Email Notifications**: Residents notified on complaint status changes and new 
  important notices
- **Dashboard**: Complaint counts by status, by category, and overdue count
